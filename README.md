# HomBites — Official App Launch Experience

A cinematic, interactive app launch experience for **HomBites**.

## Features

- **Brand-Accurate Identity**: HomBites official transparent logo and palette.
- **Warm Home-Kitchen Ambiance**: Dark rustic kitchen background with ambient copper and timber textures.
- **Interactive 3D Launch Control**: Multi-layer circular satin metallic object with smooth cursor tilt tracking.
- **Dual-Cannon Celebration Confetti**: Dual-sided confetti blast automatically cleaned up from DOM at 2.0s.
- **Persistent 45-Minute Progress Dial**: Accurate timestamp-based countdown persisting across page reloads and browser restarts.
- **Authentic Culinary Showcase**: Features the Royal Andhra Meals Thali, Chicken Curry Rice, Country Ragi Mudde, and the live mobile app mockup.

## Tech Stack

- **React 19** + **Vite 6**
- **Tailwind CSS**
- **Lucide Icons**

## Local Development

```bash
npm install
npm run dev
```

## Production Build & Deploy

```bash
npm run build
npm run preview
```
